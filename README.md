# Hangman Game

A simple text-based Hangman game developed using Python as part of my CodeAlpha internship.

## 🎮 Project Description

The player has to guess a randomly selected word one letter at a time. The player can make a maximum of 6 incorrect guesses before the game ends.

## ✨ Features

* Random word selection
* Five predefined words
* Letter-by-letter guessing
* Input validation
* Duplicate guess detection
* Maximum of 6 incorrect guesses
* ASCII Hangman display
* Win and Game Over messages

## 🛠 Technologies Used

* Python
* Random module

## 📚 Concepts Used

* Lists
* Strings
* While loops
* For loops
* If-Else statements
* User input
* Random module

## ▶️ How to Run

1. Clone or download this repository.
2. Make sure Python is installed.
3. Run the following command:

python hangman_game.py
